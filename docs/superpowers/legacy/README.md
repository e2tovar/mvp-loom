# Legacy — artefactos de planificación de M0 y M1

Los milestones M0 (`001-m0-ingest-segmentation`) y M1 (`002-char-extraction-eval`)
se documentaron originalmente con un formato pesado —`plan.md`, `tasks.md`,
`research.md` y `checklists/`— dentro de su carpeta `docs/superpowers/specs/NNN/`.

A partir de M2 el proyecto unificó el flujo en **superpowers**: el `spec.md` (más
`data-model.md`, `quickstart.md` y `contracts/`) vive en `docs/superpowers/specs/NNN/`, y el plan de
implementación pasa a `docs/superpowers/plans/`. Bajo ese patrón, `plan.md`,
`tasks.md`, `research.md` y `checklists/` ya no tienen sitio en `docs/superpowers/specs/NNN/`.

Se conservan aquí como **registro histórico**: documentan cómo se planificó,
investigó y ejecutó M0/M1 (por qué LiteLLM, por qué B³, el desglose de tareas
ejecutado). No son fuente de verdad viva; el `spec.md` de cada milestone sí lo es.
